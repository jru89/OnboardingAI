  changes.

  2. Body: introduce the mental model plainly -- "Before: this is what

## Risks & Mitigations

- **Risk**: Module 4's before/after example accidentally teaches Git
  concepts despite FR-005's explicit "not a Git course" constraint.
  **Mitigation**: after writing, re-read the section and confirm it would
  make sense to someone who has never heard of Git, diffs, or commits --
  if it wouldn't, simplify further.

  8's section wording changes later. **Mitigation**: reference the *idea*
  ("treat the first reply as a draft," Module 8) rather than quoting
  Module 8's exact sentence verbatim, so the cross-reference stays valid
  even if WP05's Module 8 edits (a different, parallel work package)
  adjust nearby wording.
